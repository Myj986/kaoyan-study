# 📚 考研学习助手

一个**零依赖、纯本地**的考研学习管理网页，双击 `index.html` 即可使用（推荐 Chrome / Edge 浏览器），无需联网、无需安装任何环境。

## 🌐 在线地址

**https://myj986.github.io/kaoyan-study/**

已部署在 GitHub Pages（公开仓库 [Myj986/kaoyan-study](https://github.com/Myj986/kaoyan-study)），把网址发给同学即可使用，每人数据各自独立保存在自己的浏览器里。

### 安装到手机 / 电脑桌面（PWA）

- **安卓手机（Chrome）**：打开网址 → 点浏览器菜单 → 「添加到主屏幕」，之后像 App 一样全屏使用；
- **iPhone（Safari）**：打开网址 → 分享按钮 → 「添加到主屏幕」；
- **电脑（Chrome / Edge）**：地址栏右侧的「安装」图标，一键安装为桌面应用；
- 支持离线：第一次打开后会自动缓存全部文件，之后断网也能用（数据存在本地，联网时自动检查更新）。

### 更新线上版本

改完代码后（若改了 HTML/CSS/JS，记得把 `sw.js` 顶部的 `CACHE_VERSION` 加一，例如 `kaoyan-v1.1`）：

```bash
git add -A && git commit -m "更新说明" && git push
```

推送后 1 分钟左右自动生效；用户下次联网打开即为新版本。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏠 概览 | 考研倒计时、**关键节点条（报名/确认/准考证/初试）**、今日学习进度环、今日专注数、今日待办、**艾宾浩斯到期复习提醒**、最近错题、近 7 天 / 30 天图表 |
| ⏱ 专注番茄钟 | 可自定义专注 / 短休 / 长休时长，**环境音（白噪音/雨声）**，自动记录专注时长到"时间记录"，完成后提示音 + 桌面通知，支持"提前结束并记录" |
| 📅 时间记录 | 按日期 / 科目手动添加学习时段，自动按天分组汇总，可编辑删除 |
| 📖 学习资料 | 整理教材 / 网课 / 真题等资料，带类型、链接、备注和进度条 |
| ❌ 错题本 | 记录题目、我的答案、正确答案、错因分析、来源；掌握度三档（待复习 / 模糊 / 已掌握），**艾宾浩斯自动排期（1/2/4/7/15/30 天，到期提醒 + 复习优先）**，支持**随机抽题复习**模式 |
| ✅ 学习计划 | 每日待办清单，带科目和截止日期，逾期高亮 |
| 📊 统计 | 近 7 / 30 / 90 天 / 全部：总时长、日均、番茄数、错题掌握率、每日柱状图、科目分布、连续学习天数、15 周坚持热力图 |
| ⚙️ 设置 | 昵称、考试日期、每日目标、番茄参数、科目管理、**数据导出 / 导入备份** |

## 数据存放与备份

- 所有数据保存在**当前浏览器的 localStorage** 中，只存在这台电脑的这个浏览器里。
- 换电脑 / 换浏览器 / 清理浏览器缓存前，请先到「设置 → 导出备份」下载 JSON 文件，之后可用「导入备份」恢复。
- 建议每周导出一次备份，有备无患。
