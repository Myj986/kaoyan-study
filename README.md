# 📚 考研学习助手

一个**零依赖、纯本地**的考研学习管理网页，双击 `index.html` 即可使用（推荐 Chrome / Edge 浏览器），无需联网、无需安装任何环境。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏠 概览 | 考研倒计时、今日学习进度环、今日专注数、今日待办、最近错题、近 7 天 / 30 天图表 |
| ⏱ 专注番茄钟 | 可自定义专注 / 短休 / 长休时长，自动记录专注时长到"时间记录"，完成后提示音 + 桌面通知，支持"提前结束并记录" |
| 📅 时间记录 | 按日期 / 科目手动添加学习时段，自动按天分组汇总，可编辑删除 |
| 📖 学习资料 | 整理教材 / 网课 / 真题等资料，带类型、链接、备注和进度条 |
| ❌ 错题本 | 记录题目、我的答案、正确答案、错因分析、来源；掌握度三档（待复习 / 模糊 / 已掌握），支持**随机抽题复习**模式 |
| ✅ 学习计划 | 每日待办清单，带科目和截止日期，逾期高亮 |
| 📊 统计 | 近 7 / 30 / 90 天 / 全部：总时长、日均、番茄数、错题掌握率、每日柱状图、科目分布、连续学习天数、15 周坚持热力图 |
| ⚙️ 设置 | 昵称、考试日期、每日目标、番茄参数、科目管理、**数据导出 / 导入备份** |

## 数据存放与备份

- 所有数据保存在**当前浏览器的 localStorage** 中，只存在这台电脑的这个浏览器里。
- 换电脑 / 换浏览器 / 清理浏览器缓存前，请先到「设置 → 导出备份」下载 JSON 文件，之后可用「导入备份」恢复。
- 建议每周导出一次备份，有备无患。
